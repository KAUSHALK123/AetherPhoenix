# Database Overview

## Purpose

The database serves as the persistent storage layer for the AI Desktop Assistant platform.

Unlike traditional CRUD applications, the database stores workflow execution data, user sessions, execution history, task metadata, artifacts, permissions, logs, and AI-related information.

The architecture follows a **Local-First** approach for Version 1 while remaining cloud-ready for future expansion.

---

# Database Goals

The database should:

- Store user information
- Store chat history
- Store workflow history
- Track execution progress
- Store planner outputs
- Store task execution
- Store permissions
- Store generated artifacts
- Store execution logs
- Store recovery history
- Support rollback metadata
- Enable future scalability

---

# Security Considerations

Sensitive Information

- Never store API keys in database

- Store encrypted locally
