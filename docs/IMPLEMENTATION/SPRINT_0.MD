# Sprint 0 — Repository & Development Foundation

## Sprint Goal

Establish the complete project foundation required before implementing any application logic.

At the end of Sprint 0, every team member should be able to:

- Clone the repository
- Install dependencies
- Run the frontend
- Run the backend
- Connect to the database
- Follow the project architecture
- Submit Pull Requests following the team workflow

No business logic or AI implementation will be developed during this sprint.
