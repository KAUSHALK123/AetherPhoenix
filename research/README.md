# Research & Patent Artifacts

This folder organizes all generated research documents, visual figures/benchmarks, and python generation scripts.

## Directory Structure

```text
research/
├── docx/
│   ├── AetherPhoenix_Patent_Application.docx
│   ├── AetherPhoenix_Patent_Application_6Pages.docx
│   └── AetherPhoenix_Patent_Application_With_Drawings.docx
├── images/
│   ├── multi_metric_comparison_all_in_one.png
│   ├── radar_benchmark_chart_all_in_one.png
│   ├── research_comparison_dashboard.png
│   ├── research_comparison_graph1_latency.png
│   ├── research_comparison_graph2_recovery.png
│   └── research_comparison_graph3_throughput.png
└── scripts/
    ├── generate_6page_patent_docx.py
    ├── generate_comparison_charts.py
    ├── generate_multi_metric_visuals.py
    ├── generate_patent_docx.py
    └── generate_patent_with_drawings.py
```

## Contents

- **`docx/`**: Patent application Word specifications and formatted drafts.
- **`images/`**: High-resolution performance benchmarks, radar comparisons, latency/throughput graphs, and overall dashboards.
- **`scripts/`**: Python scripts used to synthesize the DOCX documentation and generate scientific evaluation plots.
